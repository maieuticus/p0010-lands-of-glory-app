# Quickstart

Schon eingerichtet? Direkt zum
[aktuellen Arbeitsstand](docs/DV_KONZEPT.md#aktueller-arbeitsstand).
Im Terminal zeigt `python scripts/status.py` denselben Stand an.

Die Schritte für Einrichtung, Start und Prüfungen stehen im
[DV-Konzept](docs/DV_KONZEPT.md#einrichtung).

Projektziel und Architektur werden dort konkretisiert. Danach ein abgegrenztes
Feature unter [specs/](specs/README.md) anlegen.

Die [Spec-Kit-Einrichtung](docs/DV_KONZEPT.md#spec-kit) unterscheidet Linux-Container
und native PowerShell. Die [Befehlsübersicht](docs/DV_KONZEPT.md#befehle-und-aufruforte)
erklärt Terminalbefehle; der [Feature-Ablauf](docs/DV_KONZEPT.md#feature-ablauf)
führt durch die Arbeit im Agenten-Chat.
